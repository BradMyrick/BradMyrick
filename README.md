## Projects

### [Seekr](https://github.com/kodr-pro/seekr)
An autonomous, cost-guarded coding agent. You describe a goal; a frontier model turns it into a rigid task DAG; a cheap local model grinds through every step; an AiWrangler interceptor (backed by TypeSafe AI's Jev) approves each action before it touches disk; deterministic verification gates each step; git worktrees make every run reversible.

### [AiWrangler](https://github.com/kodr-pro/AiWrangler)
Guardrails for coding agents, driven by the docs that actually govern your repo. Plan and check gates catch silent defaults, scope creep, and claims that outrun the diff, with deterministic checks first, Jev as the calibrated semantic judge, and an append-only audit ledger. Ships as an MCP server for Cursor, Claude Code, Windsurf, and opencode.

### [BitVanes](https://github.com/kodr-pro/BitVanes)
AI-guided code tours in VS Code. Parses your diff with tree-sitter, has an LLM trace the execution flow, and steps you through it in the editor. Local-first model option, zero telemetry. [Install From Open VSX](https://open-vsx.org/extension/bitvanes/bitvanes).

### [AMP: Avalanche Matchmaking Protocol](https://github.com/BradMyrick/Avalanche-Matchmaking-Protocol)
Ranked matchmaking with verifiable settlement on Avalanche. Rust matchmaker (axum, Glicko-2), Foundry contracts with N-player quorum settlement, and SDKs for Rust, TypeScript, C#, C++, Unity, and Unreal. [Play It At PlayWithAMP.xyz](https://playwithamp.xyz).

### [Golings](https://github.com/BradMyrick/golings)
A heavily reworked fork of [Mauricioabreu/Golings](https://github.com/mauricioabreu/golings) built to match the Rustlings experience: lipgloss TUI, single-key watch mode, interactive exercise list, and saved progress.

### [Rusty-Tuber](https://github.com/kodr-pro/Rusty-Tuber)
A headless PNG-Tuber in Rust. Your mic drives a layered avatar that shows up as a virtual webcam in OBS, Zoom, and Discord.
